# Cross-platform design system implementation

Execute in this session as requested, following the audit in docs/UI_CONSISTENCY_AUDIT.md. No dependency upgrades or screen copies. Preserve current uncommitted work.

1. Geometry: create lib/design/radius.ts and tests/radius.test.js. Export getConcentricRadius(outerRadius:number, inset:number, outerSize?:{width:number;height:number}):number. Finite nonnegative inputs only; clamp radius to actual outer bounds before subtracting. Expected 28-13=15, 12-5=7, capsule(999,4,{width:200,height:48})=20, underflow=0. Test before code.
2. Platform metrics: create lib/design/platform.ts and tests/platformDesign.test.js. Export getPlatformControlMetrics(platform:string), with minimumTouchTarget 48 Android and 44 otherwise, androidRipple true Android only. Wire existing tokens, use native ripple in shared actions; retain density padding and shared typography. Test before code.
3. Material: update AppleMaterialSurface.js, forwarding radius/curve properties to native GlassView; opaque surfaceElevated Android/reduced-transparency iOS; web unchanged. Create tests/materialSurface.test.js using rendered component tree with mocked native adapters to verify availability matrix, selected/pressed layers, geometry and pointer ownership. Test before code.
4. Consumers: derive SegmentedControl child radius from actual 1pt border+4pt padding; selected material receives child inner shape. BottomNavigationBar reuses theme accessibility preference and useReducedMotion, token blur/motion, Android ripple/solid surface. Stack transitions honour reduced motion and platform defaults. Explicit Android resize in app.json. Verify changes preserve callbacks, labels, disabled and selected state via tests and fixtures.
5. Verify: full node suite, tsc, changed-file lint, full lint, expo install --check, visual export, responsive fixtures and snapshots without baseline updates. Document actual failures, modified files, before/after examples and native checks in docs/UI_CONSISTENCY_REPORT.md. Audit scope does not authorise suppressing legacy lint or changing unrelated logic.

Review focus: invalid dimensions, pill clamping, Android target growth, missing native glass API, accessibility fallback, custom asymmetric corners. Only uniformly inset matching shapes use the radius formula; document all other cases as unverified rather than claiming concentricity.
